Enviar solicitações

O envio cria um lote pendente. Nenhum serviço é cadastrado automaticamente e a base atual é preservada.

Baixar planilha modelo

Preencha o modelo a partir da linha 2 e mantenha os nomes das colunas. A planilha vem vazia, pronta para suas solicitações.

Coluna obrigatória: Descrição do Item. Opcionais: Grupo de Serviço, Código do Fornecedor, Código do Serviço, Unidade de medida e Descrição da Unidade. Deixe o código vazio para gerar um identificador LOCAL ao confirmar.

Uma solicitação por linha, sem cabeçalho. Separe os campos com ; nesta ordem:

Descrição do Item; Grupo de Serviço; Código do Fornecedor; Código do Serviço; Unidade de medida; Descrição da Unidade

Somente a descrição é obrigatória. Os demais campos podem ficar vazios; mantenha os separadores para pular um campo. Você também pode colar apenas uma descrição por linha.

Até 50.000 solicitações e 2 milhões de caracteres. Para incluir ; em um campo, envolva-o em aspas duplas. Um código vazio gera um identificador LOCAL somente após sua confirmação.
