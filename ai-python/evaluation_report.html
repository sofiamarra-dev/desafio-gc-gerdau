O que foi medido

Hit@k: pelo menos um alvo aparece entre os k primeiros. MRR@20: posição do primeiro alvo, com zero se ausente dos 20. P@5: proporção de respostas adequadas (nota 2), somente após julgar os cinco primeiros em todos os pesos, sobre o mesmo conjunto de consultas. Não são medidas de recuperação completa do catálogo.

Como interpretar a comparação

80/20, 90/10 e 95/5 usam os mesmos vetores, consultas e catálogo. Sem qualificadores, a consulta usa 100% atividade; só com qualificadores, 100% qualificadores. Essas consultas não servem para escolher o peso nominal.

A ordem do sistema prioriza código/descrição exatos e, depois, todas as palavras da consulta. “Só nota semântica” é um diagnóstico que remove essas prioridades; não é a ordenação exibida pelo aplicativo.

Cada conjunto de códigos proposto é uma hipótese, não uma lista exaustiva. Confirme a intenção, acrescente alternativas válidas e só então aprove os alvos. Fornecedores diferentes continuam aparecendo em linhas distintas, como no sistema.

Os grupos de casos estão separados em calibração e validação para uma futura mudança. Consultas da mesma família ficam no mesmo grupo. Ainda não houve ajuste nem seleção de pesos com esses casos.

As decisões ficam neste navegador. Exporte o JSON para guardar e compartilhar a revisão. Nenhuma alteração é enviada ao aplicativo.
